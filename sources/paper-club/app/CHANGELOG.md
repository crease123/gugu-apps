# 论文共读

## 0.3.0

- 一个人也能用：App 自己的页里，导入条一直在，「存放位置」可选本机的项目文件夹（也可选群）；导入后直接打开阅读页。还没有项目时，页上说明在哪里添加。手机上读不到本机项目，页上会说明。
- 一个人用时问 agent：从本机的任务里挑一个，或在论文所在的项目里新建任务；原文、页码、项目和路径放进那个任务的输入框，由你发出。需要新权限「读取本机任务」（agents:read:all）和「新建任务」（agents:control）。
- agent 的工具认本机项目里的论文（参数 `project` + `path`）；`cite` 对本机的论文给出指向文件的链接（`路径#page=…&h=…`），在任务里点一下回到原文那一处。
- 本机项目里也能导入 DOI 和链接（由本机的程序下载），不只限 arXiv。
- 需要支持 App 接口 7 的咕咕（任务聊天里的文件链接带位置）；更早的咕咕在市场上拿到的仍是 0.2.0。

## 0.2.0

- 每处划线旁边显示它在群里被讨论过几次（群消息里指向这一段的胶囊）；点开就是那几条消息，再点一条跳到群里那一条。需要新权限「读群消息」（chat:read），以及支持 App 接口 6 的咕咕。
- 每个地方都能用：App 自己的页（左栏图标）里的论文库，点一篇就在原地打开同一个阅读页；群右栏、私聊、话题、任务页签里的阅读页都一样，顶栏都能导入。
- 任务里的 PDF：笔记写在工作区里 PDF 旁边；问 agent 时，原文、页码和路径放进任务的输入框（任务里的 PDF 没有胶囊）；做不了的地方（「讨论过几次」）会当场说明原因。
- agent 的工具也认任务工作区里的 PDF（参数 `path`）。

## 0.1.2

- 图标改回不带咕咕形象：蓝底上一页论文、一行黄色高亮，加一个讨论气泡（「共读」）。

## 0.1.1

- 新图标：戴眼镜的咕咕捧着一页论文，其中一行划了黄色高亮。和咕咕其他 App 同一个画风，小尺寸下也认得出。

## 0.1.0

- 第一版。群文件夹里的 PDF 用它打开：划线（四色）、框选图表和公式、每处划线一个讨论串；谁在读第几页，点头像跟着读。
- 选一段「问 agent」：这一段作为胶囊放进群的输入框，@ 谁、问什么由你定；agent 的回答也带胶囊，点一下回到原文那一处。
- 书架（群右栏）：贴 arXiv 编号、DOI 或链接导入一篇，或上传 PDF；每篇显示划线数、谁在读、你的掌握度。
- 学习卡：agent 出的卡都挂着原文出处；每个人的复习按间隔重复排程，错题和掌握度记在群里，换台设备接着复习。
- 给 agent 的工具：读全文、找证据、引用（返回胶囊）、评论、出卡、导入；skill `paper-club` 讲读书会里的做法。
